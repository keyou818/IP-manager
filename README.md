# 🌐 企业/校园简易 IP 台账管理系统 (IP Manager)

这是一个极简、轻量级的企业/校园内网 IP 与 VLAN 管理工具。基于 Python (Flask) 和 SQLite 开发，无需安装复杂的数据库，开箱即用，非常适用于网络管理员、实验室管理员进行 IP 地址的登记、防冲突校验和余量统计。

## ✨ 核心功能

*   **🔒 登录保护**：内置密码验证机制，防止无关人员查看或篡改数据（默认密码为 admin123，可在代码中修改）。
*   **📌 网段与 VLAN 管理**：支持自定义添加网段（CIDR 格式）、绑定 VLAN ID 及填写用途备注。
*   **📊 可视化统计**：直观的进度条显示每个网段的 IP 使用率和剩余数量（剩余不足 10 个时自动变红预警）。
*   **⚡ 联动筛选**：在下拉菜单中选择某个网段，下方的 IP 列表会瞬间无感刷新，只显示该网段的记录。
*   **🛡️ 冲突防呆校验**：
    *   录入已存在的 IP 时，系统会拦截并提醒“该 IP 已被占用（显示使用者与备注）”。
    *   录入的 IP 不在所选网段内时，系统会直接报错拒绝。
*   **📝 信息追溯**：记录每一个 IP 的使用人/设备、物理位置备注，方便出故障时快速定位。

## 🚀 如何使用

### 方式一：直接运行打包好的 EXE（推荐）
1. 在 Releases 页面下载 IP管理系统.exe。
2. 将 exe 文件放在一个单独的文件夹中，**双击运行**。
3. 程序会弹出一个黑色控制台窗口（**请不要关闭**，关闭即代表停止服务）。
4. 约 1 秒后，系统会自动在浏览器中打开 http://127.0.0.1:5000。
5. 输入默认密码 admin123 即可进入系统。
*(注：所有数据都会保存在同级目录下的 ip_manager.db 文件中，如需备份，直接复制该文件即可)*

### 方式二：源码运行（需安装 Python）
1. 克隆本项目或下载源码。
2. 安装依赖：pip install flask
3. 运行程序：python app.py
4. 在浏览器中访问：http://127.0.0.1:5000

## 🛠️ 如何打包成独立的 EXE 软件

如果您修改了代码，想要重新打包成独立的 exe 文件分发给其他人（对方无需安装 Python），请按以下步骤操作：

1. 安装 PyInstaller 工具：
   pip install pyinstaller

2. 在项目根目录（app.py 所在目录）打开终端/命令行，执行以下打包命令：
   pyinstaller -F -n "IP manager" app.py
   *(注：-F 表示打包成单文件，**不要**加 -w 参数，否则无法看到运行状态也不能通过关闭窗口退出程序)*

3. 打包完成后，在生成的 dist 文件夹中即可找到 IP manager.exe。

## ⚠️ 注意事项与安全建议

1. **修改默认密码**：在 app.py 中找到 LOGIN_PASSWORD = "admin123"，将其修改为您自己的复杂密码。
2. **修改密钥**：在 app.py 中找到 app.secret_key = '...'，建议改成一段毫无规律的随机字符，防止他人伪造登录状态。
3. **局域网访问**：如果您想把它放在服务器上，通过其他终端访问，请将代码最后一行 app.run(debug=True, port=5000) 修改为 app.run(host='0.0.0.0', debug=True, port=5000)，并放行 Windows 防火墙的 5000 端口。通过 http://服务器IP:5000 即可访问（已改）。
